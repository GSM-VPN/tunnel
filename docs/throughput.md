# 처리량과 공정성

`ThroughputMeter`는 패킷 데이터가 아닌 누적 바이트와 경과 시간만 사용해
현재 처리량을 계산합니다. 기본 목표는 서버 전체 기준 `512,000,000 bytes/s`
(512 MB/s)입니다.

`FairByteRateLimiter`는 각 세션에 같은 byte rate와 burst를 적용하는 토큰
버킷입니다. 세션 버킷은 최대 216개만 유지하며, 한 세션의 큰 burst가 다른
세션의 예산을 빼앗지 않습니다. 실제 소켓 스케줄러는 이 정책을 사용해
암호화·네트워크 측정 결과에 맞는 값을 주입합니다.

비동기 소켓 어댑터는 `DatagramQueue`에 `Vec<u8>` 소유권을 이동해 넣을 수
있습니다. 큐는 패킷 수와 총 바이트를 동시에 제한하고, 포화 시 명시적인
오류를 반환합니다. 216개 세션의 동시 admission과 상한은 회귀 테스트로
검증합니다.
